# Prisma Desktop icon

`prisma-logo-source.png` is the project-owned source artwork for the Prisma
Desktop application icon. It was generated specifically for this project on
2026-07-30 and is not copied from the Zed editor icon.

The design is an original compact neural prism: three broad facets converge on
one central node, with negative space suggesting linked knowledge. It
intentionally avoids the Zed letter/lightning glyph, Prisma ORM sail, OpenAI
knot, Microsoft window, and other recognizable software marks.

`icon.ico` is the Windows multi-resolution icon generated from that source with
the Tauri CLI.
