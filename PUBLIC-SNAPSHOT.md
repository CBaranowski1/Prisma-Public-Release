# Public snapshot scope

This is a source-only import, without the private repository's Git history. It retains application source, tests, frontend assets, desktop source, integrations, deployment recipes, generic council configurations and bundled runtime skills. The private vault/brain corpus, personal records, live credentials, specialist business configurations, internal planning and unreviewed demonstration captures are excluded. Runtime interfaces are not removed.

Configure your own providers and data. Excluding private knowledge does not supply equivalent knowledge or model weights. PostgreSQL is selectable through DATABASE_URL; the default is SQLite. Passing unit tests does not establish PostgreSQL migration parity, native desktop packaging, GPU-serving compatibility or full process sandboxing. See SECURITY.md and THREAT_MODEL.md.
