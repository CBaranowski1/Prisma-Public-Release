# Prisma — Public Release (staging)

**Status: publication staging, not yet a runnable source release.**

This repository is the public destination for a clean-history export of
the self-hosted Prisma application. The private development repository is
not being made public or copied with its historical commits.

The [public architecture topology](docs/PUBLIC-TOPOLOGY.md) documents the
FastAPI application, vanilla JavaScript client, desktop integration, agentic
tool loops, grounded answer pipeline, Council DAG, query builder, and
configurable SQLAlchemy storage (PostgreSQL via DATABASE_URL; SQLite default).

The functional source-code snapshot will be added only after checking
sensitive paths, credentials, licensing, and reproducible build behavior.
Private specialist-brain data, personal state, credentials and internal
planning are not part of the public release.

**Do not treat this repository as installable until the source export and
verification have completed.**
